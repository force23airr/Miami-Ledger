# Imported Ledger drafts

`articles.ndjson` contains the eight bundled article cards as Sanity drafts.
They intentionally remain drafts because the bundled copy is demonstration
content and does not include complete reporting or sources.

Import with `npm run sanity:seed`. The command replaces only documents with
the explicit `drafts.article.*` IDs in this file. Review, source, and complete
each draft in Studio before publishing it.
